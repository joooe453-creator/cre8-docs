# CRE8 GitBook branding

The original CRE + blue split-flap 8 tile wordmark is the selected header logo. Light and dark transparent SVG / PNG files were restored in GitBook site customization on 2026-10-07.

- `cre8-logo-light.svg` / `.png`: light backgrounds
- `cre8-logo-dark.svg` / `.png`: dark backgrounds
- `avatars/`: square 1024 × 1024 and 512 × 512 PNG exports, plus SVG, with light / dark and transparent / solid backgrounds.

Avatar files preserve the original logo proportions and add padding for circular crops. Upload the full square image without zooming in. GitBook header branding is configured in site customization settings.
