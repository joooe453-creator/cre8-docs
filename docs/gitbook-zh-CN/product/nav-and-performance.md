# NAV 与绩效

NAV 表示金库资产以计价资产衡量的估值。份额价值反映金库资产、应计收益、费用与份额数量，并随市场和操作而变化。

> 目前市场页与示例金库的绩效、持仓及历史为模拟资料（Simulated）。CRE8 尚未提供经核实的正式金库绩效记录。

## 每种数字回答不同问题

| 数字 | 代表什么 | 阅读时注意 |
|---|---|---|
| NAV／份额价值 | 按可用资产与价格资料计算的估值 | 不保证实际成交或赎回价格 |
| 预估赎回额 | 根据当时持仓与资料估计可领回的金额 | 可能与实收不同，需看最低收到额 |
| 期间报酬（Return） | 选定期间份额价值的变化 | 须看费用口径、资料期间及是否模拟 |
| 年化报酬（Annualized return） | 将某段历史报酬换算成年尺度 | 不预测未来；短期间年化容易放大变化 |
| 协议 APY／APR | 某底层市场的利率或收益指标 | 会变动，不等于整档金库扣费后报酬 |
| TVL | 金库内资产的总价值指标 | 增加可能来自新存款，不一定代表策略获利 |

## 如何读绩效图

先选择显示期间，再查看数据类型、来源与更新时间。7D、30D、90D 和 All 分别代表不同区间；短期变化与较长期结果可能不同。

例如某期间费用调整后的每份价值由 1.00 变成 1.05，该期间的份额报酬为约 5%。新增存款可能增加金库总资产，不应因此被当成份额报酬。

这是阅读例子。现在的示例图以模拟份额价值及模拟费用呈现，不是链上实绩，也不能用来推断已执行交易。

**最大回撤**（drawdown）用来描述选定资料区间内从高点到低点的下降程度。它依赖同一区间的完整数据；不代表未来最大损失，也不同于 Agent 操作损失防护。

## 估值与实收为什么不同

资产价格、协议收据价值、利息与可用流动性会变化。估值使用的价格不一定是实际换币价格，退出还可能遇到滑价、交易成本或第三方费用。

原资产赎回可能交付收据，不能只用画面上的 NAV 推论立即可兑现的金额。

## 资料缺失与过期

读不到价格、部位或市场状态时，估值可能无法成立，某些存入与新加仓也可能被阻止。最后一次成功读值只代表那个时间的状态。

遇到 Unavailable、Stale 或不完整的资料区间，请保留其状态解读，不要将缺少数字当成零收益，也不要用协议 APY 补成金库绩效。

## 供款利率与额外奖励

阅读底层市场利率时，先确认它表示资产供款利息、额外代币奖励，还是多项收益的合计。奖励可能有资格、领取、锁定及到期条件，不能预设每档金库都能取得或已计入份额价值。

供款利率也会随市场使用程度变动。高利率不表示一定有足够额度可存入，或有足够流动性可提回；需一起查看市场状态。

## 您的个人损益

您可能在不同时间存入、追加或退出，所以个人结果不一定等于金库某个期间报酬。应搭配自己的资产投入、份额变化、实际赎回及交易成本核对。

正式历史绩效的资料来源、覆盖与呈现方法，将在确定后另行更新。原型已有历史资料处理，但实作不代表已有正式上线的绩效记录。每个持有地址的成本基础与退出绩效费另计，金库图表不能代替您的实际净损益。
