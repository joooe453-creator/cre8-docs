# 角色与权限

CRE8 以金库规则限制操作范围。了解谁可以买卖、改上限、暂停与恢复，能帮助您评估管理风险。

本页描述现行原型设计；正式使用时仍须核对该金库的实际角色与设定。

## 谁可以做什么

| 角色 | 可以做的事 | 权限边界 |
|---|---|---|
| 存款人／份额持有人 | 存入、持有不可转让份额，并赎回自己的比例资产 | 不能自行更换金库 Operator；没有逐笔批准 Agent 操作的程序 |
| 创作者／Manager | 建立金库、设定策略范围、调整配置上限、暂停及按条件恢复 | 建立后不能任意新增市场或提高固定费率；执行 Agent 更换有至少 24 小时等待；Manager 身分不提供替其他持有人提款的权限 |
| Agent 执行者／Operator | 在指定资产、市场、操作与上限内配置或降低部位 | 不能任意呼叫其他合约，或凭 Operator 身分赎回其他人的份额 |
| Risk Council | 暂停金库新增风险活动；暂停后设定至少 24 小时的恢复等待 | 不负责任意重导持有人资产；恢复由 Manager 按条件办理 |
| 平台配置管理者 | 审查可供新金库使用的资产与配置，管理新金库建立是否开放 | 配置审查不是安全保证；核准新配置不会直接替换既有金库的固定市场 |
| 费用接收者 | 领取自己的应计费用；原资产退出费用可能以实物交付 | 收费身分不提供赎回别人份额的权限 |

份额持有人可以另行授权代理人处理自己的份额。这项授权的风险与 Agent 的金库操作权分开，请单独确认授权对象和额度。

## 自主操作如何发生

存款人签署存入交易后，Operator 可以使用自己的签名器，在金库规则内持续操作。之后的每次换币或供款，不会再向每一位存款人请求签名。

因此，即使您保管自己的钱包私钥，也需要评估 Operator 的策略和执行风险。存入金库的资产受共同规则管理，不能仅靠撤销钱包授权就撤回已存入的资产。

## 规则变更

金库固定资产与市场范围。创作者可以立即收紧配置上限；提高上限须先公告并等待至少 24 小时。降低上限会取消待生效的提高安排。

费率与核心市场设定在建立后固定。执行 Agent 可立即停用，更换须公告并等待至少 24 小时。若需另一组市场或操作范围，应建立另一档金库，参与者再自行判断是否参与。

## 暂停与恢复

Manager 与 Risk Council 可以暂停金库。暂停阻止新存款和新加仓，设计上保留比例退出与降低风险操作。

Risk Council 暂停后，Manager 至少等待 24 小时才能尝试恢复。等待结束仍须符合当时风险条件；跨入下一个 UTC 日不会自动取消这项等待。Risk Council 再次暂停时，等待时间重新计算。

平台也可以停止新金库建立。这与某一档金库的暂停是不同范围，不能只看网站入口是否可用判断既有部位状态。

## 外部协议仍有自己的权限

第三方协议可能由治理或管理者变更参数、升级、暂停或限制转移。代币发行人也可能有冻结、黑名单等权限。CRE8 的固定市场设定不能消除这些外部控制与风险。
