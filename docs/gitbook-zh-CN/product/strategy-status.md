# 策略与功能进度

截至 2026-10-07，CRE8 仍是原型。本页分别列出基础实作与下一版规划，不代表正式服务已开放。

## 最新基础版本

基础金库原型已有指定现货换币、持有、Venus／Lista／Aave V3 供款、买一次、定期买入、回撤买入及部分再平衡。逐资产与个人退出条件须按实际启用模式核对。

独立部位原型另有借贷及 PancakeSwap V3 LP；这些能力不能直接混入一般供款金库，也不表示所有市场、钱包与退出流程已验收。现有实作中的循环借款，不属下一版允许策略。

CRE8 AI 有方案与 credits 流程；聊天服务、点数购买及金库执行服务须各自完成部署与验收。日常策略按固定规则持续执行，不逐次呼叫聊天模型。

## 多资产、多策略产品方向

最新设计允许一座金库配置多种资产、多个策略、LP 及隔离借款部位。同一资产可分核心与交易持仓，各策略有独立额度和归属；资金不能重复配置。这比基础版本的七项资产配置更广，不能直接当成基础版本已解除容量限制。

| 规划类型 | 使用目的 | 状态界线 |
|---|---|---|
| 定期、回撤、分批买入与现货网格 | 按时间或价格条件累积／交易 | 各模式实作与验收进度不同 |
| 多资产篮子、再平衡与轮动 | 管理权重与指定候选资产 | 价格、额度及完整持仓核对是必要条件 |
| LP、区间重建与收入复投 | 提供现货流动性及管理收入 | LP 有无常损失与退出成本；同交易对换池列第二阶段 |
| 闲置稳定币及 BNB 质押 | 收取协议利息或质押分润 | 只使用逐项批准目的地，BNB 解质押可能等待 |
| 抵押借稳定币再供款 | 取得扣除债务与成本后的利差 | 要处理债务、准备金、减债与退出；不可借款再抵押循环加杠杆 |
| 共用止损／止盈及分时成交 | 按预设条件管理指定部位 | 触发与成交不能保证价格或时间 |

资产方向包括可验证 bStocks、逐项批准的主要 crypto，以及 U、USDT、USD1、USDC 等指定稳定币。资产目录不等于所有 BNB 版本已获准交易、抵押或提供 LP；上架与市场支援分别核对。

这轮不纳入期货、永续、期权、循环再抵押与跨池套利。研究或介面选项不构成执行承诺。

## 工程进度与实际可用

主线已有多资产、混合持仓及规则执行的一部分实作，包含本地测试及部分真实市场 fork 验证。尚有策略缺项及完整市场／退出验收；测试证据不表示正式部署已开放，也不能将全部工具列为已完成。

正式可用清单须同时对应部署版本、已批准市场、执行服务、费率、资格与实际退出能力。现阶段没有正式建立或入金。详见[支持的协议与操作](integrations.md)及[安全与服务状态](security-and-status.md)。
