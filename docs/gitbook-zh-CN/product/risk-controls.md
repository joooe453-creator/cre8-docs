# 风控与剩余风险

金库以指定资产与市场、配置上限、闲置要求及权限限制新增风险。这些措施不保证收益、最大亏损或退出时间，本金可能全部损失。

## 配置上限与闲置

目前基础金库最多 7 个不重复底层资产的配置项目，同一资产选一个指定目的地。各项上限总和最多 95%；Agent 新增部署后，至少 5% NAV 留作闲置计价资产。

市场波动及退出会改变后续比例，5% 不是任何时刻的现金保证。创作者可立即收紧上限，提高需公告并等待至少 24 小时。降低上限不自动卖出，市场变动也可能使既有部位比例超出上限。

## Agent 操作损失防护

防护追踪 Agent 资本动作本身造成的正 NAV 损失，使用动作前后相同价格条件比较，与市场价格变动造成的持仓损失不同。预设及平台上限为 5%，观测涵盖最近约 24 小时，最旧纪录可能多保留近一小时。

**触及门槛的动作先完成，再停用 Agent。** 因此 5% 不是单笔、累计或整座金库总损失的硬上限，亦不是连续市场监控或保证止损。停用 Agent 与全面暂停金库不同；持有人退出与管理者降低部位仍有各自的操作路径。

## 止损、止盈与持续执行

原型有逐资产及个人止损／止盈流程，触发范围与收款人须分开确认。目标价不保证成交价；行情失效、网路延迟、流动性不足或执行服务中断都可能使退出延迟或失败。

多资产、多策略的进一步规划与实作状态见[策略与功能进度](strategy-status.md)。设定条件不代表所有模式已部署，也不代表出现触发讯号就必定可成交。

## 暂停与执行者更换

Manager 或 Risk Council 可按规则暂停，保留降低部位与持有人退出路径。Risk Council 暂停后，Manager 恢复需至少 24 小时并满足风险条件。执行 Agent 可立即停用；更换须公告并等待至少 24 小时。

上述安排不能解除第三方协议升级、冻结、黑名单、收据转移失败或网路限制。

## 其他风险

| 类型 | 可能影响 |
|---|---|
| 市场、稳定币与发行人 | 贬值、脱钩或资产权利改变 |
| Agent 与智能合约 | 有权限的交易仍可能亏损，漏洞或整合错误亦可能造成损失 |
| 资料与预言机 | 估值不可靠，新增或退出操作受阻 |
| 第三方流动性与治理 | 暂停、提款不足、费用变动或失去偿付能力 |
| LP 与借款规划 | 无常损失、利率变动、负债与清算风险；不能用供款风险概括 |
| 法律与资格 | 某功能或移转无法提供 |
