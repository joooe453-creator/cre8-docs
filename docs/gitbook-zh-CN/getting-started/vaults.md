# 基金如何运作

一只 CRE8 基金把多位持有人的资产放在同一套规则（mandate）下管理。每只基金都是一个非托管的金库合约。创作者设定基金可持有的资产、指定市场与配置上限，再指定一个 AI agent（即 Operator 角色），并选择基金日常由谁运行：在链上执行的计划，或在规则内自行决定的 AI agent。持有人取得基金份额，份额价值依规则随基金资产变化。

目前为原型，本页说明现行设计；正式建立与存入尚未开放。

## 资金经过哪些步骤

1. **创作者设定基金。** 选择资产与目的地、各项配置上限、AI agent 及固定绩效费。资产与市场组合须符合已审查的执行范围。
2. **创作者投入种子资金。** 完成建立时投入 100 单位计价资产。基金上线时收一次 1% 建立费，标准净投入为 99 单位；种子不另收存入费。没有固定时间锁；其他持有人仍在时，创作者须维持至少 2% 流通份额。种子资金先保持闲置，计划或 AI agent 再依规则配置。
3. **持有人存入计价资产。** 每次存入收 1% 存入费。持有人按当时的份额价格取得份额。基金持有部位期间仍可接受符合条件的新存款。
4. **计划或 AI agent 执行允许的操作。** 计划的每个排定步骤由 keeper 交易送上链；AI agent 则在规则内自行决定。两者都可以买卖指定资产、持有代币，或把资产存入指定协议。每次新加仓须符合配置上限与闲置要求。
5. **持有人选择提取方式。** **以 USDT 提取**：把自己那份持仓卖成计价资产。**直接提取资产**：按比例领取原资产与协议收据。

基金持续运作，持有人提取时只处理其比例持仓。一般持有人没有固定锁定期；实际提取仍有价格、费用、流动性和第三方限制。

## 计价资产、持仓资产与收据

| 类型 | 用途 | 例子 |
|---|---|---|
| 计价资产 | 份额价格的计价单位，并用于存入及以 USDT 提取 | 某只基金指定 USDT |
| 持仓资产 | AI agent 可以买入或持有的资产 | 已核准的代币 |
| 协议收据 | 记录已存入借贷市场或第三方金库的部位 | 借贷收据或第三方金库份额 |
| CRE8 基金份额 | 记录您在这只基金的持有比例 | 存入后取得的 shares |

上述资产具有不同用途。协议收据能否转让或换回底层资产，取决于原协议及代币条件；CRE8 份额价格则反映基金资产、费用与提取结果。

## 规则与计划

**配置上限**限制 AI agent 新增部位时，可以投入多少基金价值。**目标权重、计划描述或再平衡指示**表达创作者希望基金如何运作，但未由现行执行功能支持的指示，不会因为写进设计就自动执行。

例如「某资产最多 30%」是配置限制；「每周调回 20%」还需要相应 AI agent 与执行安排，须核对该基金实际启用的自动化模式。买一次、定期、回撤买入及部分再平衡已有原型实作；多资产计划的完整进度见[计划与功能进度](../product/strategy-status.md)。

## 哪些设定固定

现行设计中，计价资产、指定市场、创作者、风险管理角色及绩效费在建立时固定。创作者可以立即收紧配置上限；提高上限须先公告并等待至少 24 小时。加入新市场需要建立另一只基金。AI agent 可立即停用；更换须公告并等待至少 24 小时。

如果您想了解谁能暂停、恢复或执行操作，请读[角色与权限](../product/permissions.md)。
