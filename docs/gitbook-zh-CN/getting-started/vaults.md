# 金库如何运作

一档 CRE8 金库把多位参与者的资产放在共同规则下管理。创作者设定可投资资产、指定市场与配置上限，再指定一个 Agent 的执行者（Operator）。存款人取得金库份额，依规则参与资产价值的变化。

目前为原型，以下流程说明现行设计；正式建立与存入尚未开放。

## 资金经过哪些步骤

1. **创作者设定金库。** 选择资产与目的地、各项配置上限、Operator 及固定绩效费。资产与市场组合须符合已审查的执行范围。
2. **创作者投入种子资金。** 完成建立时投入 100 单位计价资产，适用 0.5% 入场费。没有固定时间锁；其他持有人仍在时，创作者须维持至少 2% 流通份额。建立完成时，资金先保持闲置，Agent 再依规则配置。
3. **存款人存入计价资产。** 存款人按当时定价取得份额。金库持有部位期间仍可接受符合条件的新存款。
4. **Agent 执行允许的操作。** Agent 可以买卖指定资产、持有代币，或把资产存入指定协议。每次新加仓须符合配置上限与闲置要求。
5. **持有人选择退出。** 持有人可按自己的份额，选择赎回为计价资产，或按比例领取原资产与协议收据。

金库持续运作，存款人退出时处理其比例持仓。一般持有人没有现行产品设定的固定锁定期；实际退出仍有价格、费用、流动性和第三方限制。

## 计价资产、持仓资产与收据

| 类型 | 用途 | 例子 |
|---|---|---|
| 计价资产 | 表示 NAV，并用于存入及计价资产赎回 | 某档金库指定 USDT |
| 持仓资产 | Agent 可以买入或持有的资产 | 已核准的代币 |
| 协议收据 | 记录已存入借贷市场或第三方金库的部位 | 借贷收据或第三方金库份额 |
| CRE8 金库份额 | 记录参与者在这档金库的参与比例 | 存入后取得的 shares |

上述资产具有不同用途。协议收据能否转让或兑回，取决于原协议及代币条件；金库份额的价值则反映金库资产、费用与退出结果。

## 规则与策略指示

**配置上限**限制 Agent 新增部位时，可以投入多少金库价值。**目标权重、策略描述或再平衡指示**可以表达创作者希望 Agent 如何操作，但未由现行执行功能支持的指示，不会因为写进设计就自动执行。

例如「某资产最多 30%」是配置限制；「每周调回 20%」还需要相应 Agent 与执行安排，须核对该金库实际启用的自动化模式。买一次、定期、回撤买入及部分再平衡已有原型实作；多资产混合策略的完整进度见[策略与功能进度](../product/strategy-status.md)。

## 哪些设定固定

现行设计中，计价资产、指定市场、创作者、风险管理角色及绩效费在建立时固定。创作者可以收紧配置上限；提高上限须先公告并等待至少 24 小时。加入新市场需要建立另一档金库。执行 Agent 可立即停用；更换须公告并等待至少 24 小时。

如果您想了解谁能暂停、恢复或执行操作，请读[角色与权限](../product/permissions.md)。
