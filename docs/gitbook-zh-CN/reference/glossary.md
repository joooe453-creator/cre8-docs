# 名词解释

| 名词 | 在 CRE8 文件中的意思 |
|---|---|
| Fund／基金 | 持有人共同持有份额、依合约执行的规则运作的一组资产；每只基金都是一个非托管的金库合约 |
| Thesis／基金主张 | 基金押注的一句话想法，显示在基金页面最上方 |
| Mandate／基金规则 | 基金不能违反的规则：可持有的资产、每项资产的上限及可使用的协议，由合约强制执行 |
| Plan／计划 | 基金自动执行的事：何时买入、多久再平衡、何时止盈 |
| Run by／运行方式 | 基金日常由谁运行：`Plan`（计划）或 `AI agent` |
| Creator／创作者 | 建立基金、设定规则与固定绩效费、指定 Operator，并依权限管理上限和暂停的角色 |
| Holder／持有人 | 持有基金份额的人 |
| CRE8 AI | CRE8 的助手：协助起草与比较基金，不碰您的资金 |
| AI agent | 创作者自己的 AI，在规则内运行标示为「Run by: AI agent」的基金 |
| Operator／执行者 | 基金指定的执行角色，使用自己的签名器在规则内操作 |
| Risk Council | 可暂停基金新增风险活动的风险管理角色 |
| Shares／份额 | 记录您在基金中的持有比例与提取权利的单位，目前不可转让 |
| Creator stake／创作者持有比例 | 创作者自己持有的基金比例；其他持有人仍在时至少 2% |
| Cost basis／成本基础 | 每个持有地址的净投入记录，部分提取按份额比例分摊 |
| CRE8 AI credits／AI 点数 | 支付聊天及方案服务的帐户额度，不可转让或提领 |
| Accounting asset／计价资产 | 表示份额价格、用于存入及「以 USDT 提取」的代币 |
| Underlying／底层资产 | 部位或协议收据所对应的实际资产 |
| Market／指定市场 | 资产被允许交易或出借的具体协议市场 |
| Lending／借贷 | 将资产存入指定借贷市场或第三方金库以取得利息 |
| Receipt／协议收据 | 记录存入第三方协议的部位，例如借贷收据或金库份额 |
| Share price／份额价格 | 一份额以计价资产表示的价值，受资产、费用与份额变化影响；技术文件称为每份净资产价值（NAV） |
| Fund size／基金规模 | 基金资产的总价值 |
| Holdings／持仓 | 基金持有哪些资产及其比例 |
| Cap／配置上限 | 新加仓时某项资产允许占基金价值的最大比例 |
| Target weight／目标权重 | 计划希望达到的配置比例；不能据此推论已自动执行 |
| Idle reserve／闲置资产 | 尚未部署到第三方部位的基金计价资产 |
| Creation fee／建立费 | 创作者种子的 1%，基金上线时收一次 |
| Deposit fee／存入费 | 每次存入的 1%（种子除外），归 CRE8 |
| Performance fee／绩效费 | 对该地址本次提取的正收益收取的费用：CRE8 10% 加创作者 0–20% |
| Seed／种子资金 | 创作者建立基金时投入的 100 单位计价资产 |
| Withdraw as USDT／以 USDT 提取 | 把您的比例持仓卖成计价资产；不是银行出金 |
| Withdraw as assets／直接提取资产 | 按比例直接交付原持仓资产、协议收据及闲置资产 |
| Fund facts／基金资料 | 基金的费用、规则版本、创作者持有比例及资料来源 |
| Deposits paused／暂停存入 | 停止接受新存入，一定附上原因；提取不受影响 |
| Slippage／滑价 | 预期与实际成交价格之间的差异 |
| Price impact／价格影响 | 一笔交易的规模对其可成交价格造成的影响，与池内流动性有关 |
| Minimum received／最低收到额 | 使用者接受的最低操作结果；未满足时交易失败 |
| Deadline／期限 | 本次交易允许执行的最晚时间 |
| Allowance／授权额度 | 授权某地址动用特定代币或份额的额度；不同授权需分别确认 |
| Oracle／预言机 | 提供资产价格等外部资料的来源 |
| APR／APY | 部分协议公布的年化利率；CRE8 不为基金显示这类数字，计算口径与是否含复利须看来源 |
| Performance／业绩 | 7D、30D、90D 或 All 期间扣费后的份额价格变化 |
| Max drop／最大回撤 | 所选区间内从高点向低点下降的幅度 |
| Simulated／模拟 | 为展示或研究生成的资料，不是正式链上实绩 |
| Stale／过期 | 资料已超过有效时限，不能代表目前状态 |
| MCP | Agent 与工具交换资讯的接口；CRE8 的交易准备功能不收私钥、不签名或广播 |
| Non-custodial／非托管 | CRE8 不保管持有人的私钥；基金内的资产仍受基金规则与 Operator 操作影响 |

名词解释方便阅读，实际条件仍需搭配[产品规则](../product/permissions.md)、[费用](../product/fees.md)和[使用条款草稿](../legal/terms.md)。
