# 名词解释

| 名词 | 在 CRE8 文件中的意思 |
|---|---|
| Vault／金库 | 多位参与者依共同规则存入与持有资产的安排 |
| Mandate／金库规则 | 允许的资产、市场、操作与配置限制 |
| Creator／Manager／创作者 | 设定金库范围、指定 Operator，并依权限管理上限和暂停的角色 |
| Agent | 可协助分析、准备或执行操作的程式；实际权限取决于角色与金库设定 |
| Operator／执行者 | 金库指定的执行角色，使用自己的签名器在规则内操作 |
| Risk Council | 可暂停金库新增风险活动的风险管理角色 |
| Shares／份额 | 金库记录的参与比例与赎回权利单位，目前不可转让 |
| Cost basis／成本基础 | 每个持有地址的净投入记录，部分退出按份额比例分摊 |
| CRE8 AI credits／AI 点数 | 支付聊天及方案服务的帐户额度，不可转让或提领 |
| Accounting asset／计价资产 | 表示 NAV 并用于存入及计价资产赎回的代币 |
| Underlying／底层资产 | 部位或协议收据所对应的实际资产 |
| Market／指定市场 | 资产被允许交易或存入的具体协议市场 |
| Supply／供款 | 将资产存入指定借贷市场或第三方金库 |
| Receipt／协议收据 | 记录存入第三方协议的部位，例如借贷收据或金库份额 |
| NAV／净资产价值 | 以计价资产表示的金库资产估值 |
| NAV per share／每份价值 | 份额对应的估值，受资产、费用与份额变化影响 |
| TVL | 金库内资产的总价值指标 |
| Cap／配置上限 | 新加仓时某项资产允许占金库价值的最大比例 |
| Target weight／目标权重 | 策略希望达到的配置比例；不能据此推论已自动执行 |
| Idle reserve／闲置资产 | 尚未部署到第三方部位的金库计价资产 |
| Performance fee／绩效费 | 对该地址本次退出正收益收取的费用 |
| Seed／种子资金 | 创作者建立金库时投入的 100 单位计价资产 |
| Cash redeem／计价资产赎回 | 把退出者的比例持仓处理成计价代币，没有承诺银行出金 |
| In-kind redeem／原资产赎回 | 按比例交付原持仓资产、协议收据及闲置资产 |
| Slippage／滑价 | 预期与实际成交价格之间的差异 |
| Price impact／价格影响 | 一笔交易的规模对其可成交价格造成的影响，与池内流动性有关 |
| Minimum received／最低收到额 | 使用者接受的最低操作结果；未满足时交易失败 |
| Deadline／期限 | 本次交易允许执行的最晚时间 |
| Allowance／授权额度 | 授权某地址动用特定代币或份额的额度；不同授权需分别确认 |
| Oracle／预言机 | 提供资产价格等外部资料的来源 |
| APR／APY | 年化利率或收益率指标，是否含复利与计算口径须看来源 |
| Return／报酬 | 选定期间的价值变化，须确认费用与数据口径 |
| Annualized return／年化报酬 | 把已观测期间报酬换算成年尺度，没有预测未来 |
| Drawdown／回撤 | 所选区间内从高点向低点下降的幅度 |
| Simulated／模拟 | 为展示或研究生成的资料，不是正式链上实绩 |
| Stale／过期 | 资料已超过有效时限，不能代表目前状态 |
| MCP | Agent 与工具交换资讯的接口；CRE8 的交易准备功能不收私钥、不签名或广播 |
| Non-custodial／非托管 | CRE8 不保管存款人的私钥；存入金库的资产仍受共同规则与 Operator 操作影响 |

名词解释方便阅读，实际条件仍需搭配[产品规则](../product/permissions.md)、[费用](../product/fees.md)和[使用条款草稿](../legal/terms.md)。
