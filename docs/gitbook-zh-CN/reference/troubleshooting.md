# 操作问题排查

先确认您正在操作的是示例、测试环境或正式部署。截至 2026-10-10，正式建立与存入未开放；原型中的「部署待完成」或「法律安排未完成」不会靠更改钱包设定解除。

## 按问题检查

| 遇到的情况 | 先看什么 | 接下来怎么做 |
|---|---|---|
| 网路不符 | 帐户、网路及选定资产 | 切换至该操作指定网路后重新读取；主网与测试网资产不能混用 |
| 找不到可用配置 | 完整资产与目的地组合是否在支持范围内 | 保留设计，勿把其他协议地址当成同一个市场 |
| 资产或网路费不足 | 可用代币、创作者最低持有要求及支付网路费的资产 | BNB Smart Chain 交易需要该网路的 BNB 支付费用；重新核对本次金额 |
| 授权完成但未存入 | 是否只有授权交易成功 | 分别核对授权与存入结果，确认原存入尚未送出再继续 |
| 新存款或加仓被阻止 | 是否暂停存入及原因、配置上限、闲置要求及市场额度 | 读取最新状态；资料或条件不符时停止该次新增风险操作 |
| 份额价格或资产价格不可得 | 资料时间、来源与部位是否完整 | 等待可核实读值；需要提取时了解直接提取资产的方式及其限制 |
| 最低收到额未满足 | 最新预估、滑价、流动性与费用 | 重新评估是否接受新价格，再准备交易；勿只为成交而盲目降低最低额 |
| 交易已过期 | 本次期限与签署时间 | 按新状态重新准备，勿直接沿用旧预览 |
| 以 USDT 提取失败 | 哪个市场无法提回或换币，是否满足最低额 | 核对失败交易，再评估直接提取资产；领到的协议收据仍可能无法从原协议提回 |
| 直接提取资产失败 | 代币或收据转移限制、网路费、接收地址 | 查明外部限制，不因选择直接提取资产就推定所有限制解除 |
| 交易结果未知 | 原交易杂凑与本次操作资料 | 先查询原交易，勿自动重送 |
| 交易已上链但没有完成买入 | 实际执行结果与暂停状态 | 确认是否仅执行风险检查或阻止加仓；勿记为成交 |

## CRE8 AI 与点数问题

| 情况 | 处理方式 |
|---|---|
| 点数购买尚未入帐 | 核对原订单与交易，等待最终确认；勿再次付款 |
| 点数不足 | 本次余额须涵盖显示上限；补足后再开始，或直接使用基金操作 |
| 同时有请求执行中 | 等待原请求完成并查询状态，勿重复建立任务 |
| AI 未交付 | 目前点数模式没有交付不扣点；保留任务与余额纪录供核对 |
| 修改需要点数 | 每次修改交付另按用量扣点，确认本次上限及原任务范围 |
| AI 不可用或免费额度耗尽 | 直接查询、提取及权限管理不依赖 AI 点数，仍受基金及服务条件限制 |

详见[CRE8 AI 与 credits](../guides/cre8-ai-credits.md)。

## 滑价与价格影响

**价格影响**（price impact）是交易规模对可成交价格造成的影响；流动性较浅时，大额换币可能取得较差价格。

**滑价**（slippage）是预览与实际成交之间的差异，也可能来自市场波动和确认延迟。两者都可能减少实收，不能仅靠放宽最低收到额消除。

如果交易失败，仍可能支出网路费。重新准备前先核对原交易结果；钱包、网路或操作条件改变后，旧的阅读与交易确认需要重新检查。

## 保留哪些资讯

保存网路、基金、动作、金额、时间、原交易杂凑和画面错误。不要在错误回报或对话中贴私钥、助记词与不必要的个人资料。
