# Agent 使用指南

CRE8 的 Agent 工具协助读取基金状态、检查操作条件、准备交易与模拟结果。MCP 提供未签署交易资讯，不收取私钥、不自行签名，也不代替钱包广播交易。

> 正式基金及正式 MCP 服务尚未核实开放。网站示例或下载文件，不代表已有可接收真实操作的服务；本页说明产品使用流程。

## AI 模型

CRE8 AI 采用 **Anthropic Claude Sonnet 5.5**，用于对话与方案生成，包括比较基金（Compare funds）、设计基金（Design a fund）及检查计划（Review a plan）。模型输出不会授予交易或 AI agent 权限。

CRE8 AI 的聊天、价格与用量收费，另见[CRE8 AI 与 credits](cre8-ai-credits.md)。日常计划执行按既定规则运作，不逐次呼叫聊天模型或消耗 AI 点数。

## 区分两种使用场景

**持有人的操作助理**可以协助解释基金、准备存入或提取。最终由该持有人的钱包确认相关交易。

**基金的 AI agent**（即 Operator 角色）由创作者指定，在固定范围内使用自己的签名器配置基金资产。持有人不会逐笔批准这些后续交易。

请勿把两者混为一谈。能解释一只基金，不代表操作助理具有该基金 AI agent 的权限。

## 操作顺序

### 1. 读取状态

确认网路、基金、角色、资产与市场、上限、是否暂停存入及其原因、费率及待生效变更。看清数据时间、可用性及部署状态。

对示例、未部署或无法核实的配置，只能阅读或准备设计，不能视为可执行的正式操作。

### 2. 准备允许的操作

依角色与基金规则（mandate）准备建立、存入、提取、配置、降低部位或风险检查。指定资产、金额、接收者、最低可接受结果与期限。

计划文字或自然语言指示不能增加操作权。指定目的地不可用时，Agent 也不能擅自改用另一个市场。

### 3. 检查与模拟

用最新可得状态检查交易。模拟是当时条件下的预览，不会替您保存风险状态、执行交易或锁定成交价格。

钱包、网路、资产、金额或交易条件改变后，需要重新检查。模拟后市场仍可能改变，正式交易结果也可能不同。

### 4. 由有权限的钱包签署

签名前核对动作、网路、资产、金额、接收者、授权对象与额度、最低收到额及期限。签名器必须对本次操作有相应权限。

不要把私钥或助记词贴进对话、网站或文件阅读栏位。MCP 的交易准备功能不需要取得它们。

### 5. 确认实际结果

交易杂凑表示有一笔可追踪的交易，不单凭杂凑判断完成。核实交易结果与实际动作，再核对收到的份额或资产，以及更新后状态。

例如新加仓检查可能保留暂停结果而没有实际投入资金。Agent 不应只因交易已上链，就把该操作记成完成买入。

## 结果不明时

保留原交易杂凑与本次操作资料，先查询同一笔交易。确认它是等待中、失败、已完成，还是因替换或网路状态需要进一步核对。

画面逾时或暂时查不到交易，不足以决定自动重送。重复送出可能造成重复建立、存入或提取。交易确定失败后，再按当时状态重新准备。

## Agent 的说明与承诺

Agent 应清楚标示示例、估算、模拟、等待确认及已核实结果，不将未支持的规划说成可执行能力，也不承诺本金、业绩或提取时间。

可用操作请见[支持的协议与操作](../product/integrations.md)，权限请见[角色与权限](../product/permissions.md)。
