# 持有人指南

选择基金时，先看自己能否理解它的操作范围与提取条件。相同资产或相似业绩数字的基金，可能有不同的创作者、AI agent、配置上限及第三方风险。

> 目前示例基金与业绩均为模拟，不能用来判断真实管理能力，也不能接受正式存入。

## 评估一只基金

| 要看什么 | 要弄清楚的问题 |
|---|---|
| 状态与网路 | 是示例、测试环境，还是经核实的正式基金？使用哪个网路？ |
| 计价与持仓资产 | 存入什么？基金可以买什么？是否有价格或脱钩风险？ |
| 指定市场 | 资产会存入哪些协议？收据如何换回底层资产？ |
| 创作者与 AI agent | 谁设定计划？哪个 AI agent 自主执行？哪些角色可以暂停基金？ |
| 配置上限 | 单一资产最多可投入多少？是否有待生效的变更？ |
| 费用 | 每次存入收 1% 存入费。总绩效费多少（CRE8 10% + 创作者）？如何判断可计费获利？还有哪些成本，例如 gas、DEX 手续费与滑价？ |
| 业绩数据 | 是 simulated、估算或真实历史？覆盖多久、数据何时更新？ |
| 提取 | 可以领回哪些资产？如果流动性或估值失效，会发生什么？ |

## 您取得什么

您存入计价资产后，取得由基金记录的份额。份额让您依规则分享基金的资产价值与提取结果；获利或亏损都会影响份额价格。

份额不可转让，也不是保本凭证。每个持有地址各自记录净投入的成本基础，用于提取时收取的绩效费；详见[费用](../product/fees.md)。

## 存入后谁操作

AI agent 在基金指定范围内使用自己的签名器操作。持有人不会逐笔签核后续买卖或供款。

单一持有人不能自行更换基金的 AI agent。创作者可依治理流程停用 AI agent，或在等待期后更换。撤销自己钱包的代币授权，会影响授权对象日后能否从该钱包取得资产，不会撤销 AI agent 对已存入基金资产的操作权。

AI agent 的角色不赋予替您提取的特殊权限。若您另行授权他人处理自己的基金份额，该授权需要单独核对。

## 如何持续查看

留意持仓、配置与上限、最新数据时间、是否暂停存入及其原因，以及已公告但尚未生效的上限变更。数据不可得时，不要把空白、过期数字或示例图表当成目前资产状态。

正式业绩记录尚未建立。目前页面显示的模拟业绩，只用来展示阅读方式，请读[份额价格与业绩](../product/nav-and-performance.md)。
