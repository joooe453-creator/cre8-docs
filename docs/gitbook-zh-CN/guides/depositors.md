# 存款人指南

选择金库时，先看自己能否理解它的操作范围与退出条件。相同资产或相似绩效数字的金库，可能有不同的创作者、Operator、配置上限及第三方风险。

> 目前示例金库与绩效均为模拟，不能用来判断真实管理能力，也不能接受正式资金。

## 评估一档金库

| 要看什么 | 要弄清楚的问题 |
|---|---|
| 状态与网路 | 是示例、测试环境，还是经核实的正式金库？使用哪个网路？ |
| 计价与持仓资产 | 存入什么？金库可以买什么？是否有价格或脱钩风险？ |
| 指定市场 | 资产会存入哪些协议？收据如何赎回？ |
| 创作者与 Operator | 谁设定策略？谁自主执行？哪些角色可以暂停？ |
| 配置上限 | 单一资产最多可投入多少？是否有待生效的变更？ |
| 费用 | 总绩效费多少？如何判断可计费收益？还有哪些成本？ |
| 绩效资料 | 是 simulated、估算或真实历史？覆盖多久、资料何时更新？ |
| 退出 | 可以领回哪些资产？如果流动性或估值失效，会发生什么？ |

## 您取得什么

您存入计价资产后，取得由金库记录的份额。份额让您依规则参与金库的资产价值与赎回结果；获利或亏损都会影响份额价值。

份额不可转让，也不是保本凭证。每个持有地址各自记录净投入的成本基础，用于退出绩效费；详见[费用](../product/fees.md)。

## 存入后谁操作

Operator 在金库指定范围内使用自己的签名器操作。存款人不会逐笔签核后续买卖或供款。

单一存款人不能自行更换金库 Operator。创作者可依治理流程停用或延迟更换执行 Agent。撤销自己钱包的代币授权，会影响授权对象日后能否从该钱包取得资产，不会撤销 Operator 对已存入金库资产的操作权。

Operator 的角色不赋予替您提款的特殊权限。若您另行授权他人处理自己的金库份额，该授权需要单独核对。

## 如何持续查看

留意持仓、配置与上限、最新资料时间、暂停状态，以及已公告但尚未生效的上限变更。资料不可得时，不要把空白、过期数字或示例图表当成目前资产状态。

正式绩效记录尚未建立。目前页面显示的模拟绩效，只用来展示阅读方式，请读[NAV 与绩效](../product/nav-and-performance.md)。
