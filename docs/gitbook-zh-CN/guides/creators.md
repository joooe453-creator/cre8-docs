# 创作者指南

创作者决定一只基金的操作范围，并指定执行计划的 AI agent。您设定的内容会影响持有人承担的资产风险、费用和提取方式。

> 目前可设计与汇出基金方案，正式建立尚未开放。汇出档不会建立基金、投入种子资金或自动买入资产。

## 建立前先定义计划

写出持有人能理解的计划摘要：打算持有哪些资产、使用哪些市场、何时可能调整、主要风险，以及什么情况可能无法提取。摘要应与实际允许的操作一致。

计划名称、AI 描述或目标配置不会自行增加功能。定期买入、回撤买入、再平衡等指示，只有在相应操作确实支持时才可执行。

## 设计基金的顺序

1. **设定名称与计价资产。** 确认持有人存入的代币，以及份额价格与以 USDT 提取所用单位。
2. **选择持仓资产。** 现行设计基础基金最多 7 个、不重复的资产配置项目。
3. **选择目的地。** 为每项资产选择持有、已核准第三方金库或供款市场。同一资产只能绑定一个指定目的地。
4. **设定上限。** 各项上限总和不得超过基金价值的 95%；每次新加仓完成后至少留 5% 在基金闲置。
5. **指定 AI agent。** 使用独立于创作者钱包的 AI agent 地址（即 Operator 角色），确认它能在指定范围内执行。格式正确不代表其管理能力已核实。
6. **设定创作者绩效费。** 范围为每位持有人提取时自己已实现获利的 0–20%（预设 10%），建立后固定；另有 CRE8 固定 10%，合计 10–30%。基金页显示合并后的一个数字，例如「绩效费 25%（CRE8 10% + 创作者 15%）」。持有人每次存入另付 1% 存入费。没有年费、管理费或操作费。
7. **检查完整方案。** 资产与市场组合须符合经审查的执行配置；符合设计栏位不代表已获准上线。

## 种子资金

正式建立时，创作者须投入 100 单位计价资产。基金上线时对种子收一次 1% 建立费，标准净投入为 99 单位。种子不另收存入费；您之后追加的存入，和其他人一样收 1% 存入费。份额不可转让，没有固定 90 天锁定；其他持有人仍在时，创作者提取后须维持至少 2% 流通份额。

这项要求表达创作者的初始投入，不承诺基金业绩，也不能弥补其他持有人的损失。种子资金先保持闲置；计划或 AI agent 后续再依规则配置。

## 建立后可改什么

| 设定 | 现行规则 |
|---|---|
| 配置上限收紧 | 可立即生效；收紧会取消待生效的上限提高 |
| 配置上限提高 | 先公告并等待至少 24 小时，之后按程序生效 |
| 新增市场或更换目的地 | 需要建立另一只基金 |
| 创作者与风险管理角色 | 建立后固定 |
| AI agent | 可立即停用；更换需公告并等待至少 24 小时 |
| 创作者绩效费与收费地址 | 建立后固定；CRE8 绩效费固定 10% |
| 暂停与恢复 | 依角色权限、等待时间及当时风险状态处理 |

降低上限不会自动卖出既有部位。价格变化也可能使持仓比例超过某项上限；AI agent 新加仓仍须通过当时的规则检查。

## 向持有人说明

基金介绍应清楚列出计划类型、资产、市场、上限、AI agent、费率、利益分配与主要风险。业绩要标示真实或模拟及数据期间。

避免把未支持的功能、未经核实的部署或未完成的审计写成现成能力。创作者收取绩效费，须让持有人了解这项经济利益及可能的利益冲突。

创作者应按实际管理、推广与所在地确认资格和责任。CRE8 的正式营运主体与市场目前尚未决定，不能因完成设计就开始接受正式存入。
