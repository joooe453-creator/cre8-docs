# Welcome to CRE8

美股和加密资产，从 NVIDIA 到 Bitcoin，放进同一只基金。用一句话描述它：CRE8 AI 帮您建好，规则（mandate）让它说到做到。

CRE8 让创作者建立由合约执行规则的基金。每只基金由计划或创作者自己的 AI agent 运行，只能在指定资产、市场与配置上限内操作。持有人存入基金的计价资产，取得代表持有比例与提取权利的份额。

创作者决定操作范围，计划或 AI agent 在范围内执行，持有人依基金规则持有或提取份额。选择基金前，您可以先了解谁有操作权、资产可以放在哪里、费用如何计算，以及提取可能遇到的限制。

> **目前状态｜2026-10-10**：CRE8 为未经第三方审计的原型，尚无经核实、可接受正式资金的部署。示例基金、持仓与业绩为模拟资料；本文描述现行产品设计，不表示正式服务已开放。

## 三个核心概念

**基金规则**（mandate）定义基金可以持有的资产、指定市场、配置上限与操作范围。规则由合约执行，计划或 AI agent 都不能越过。

**基金份额**（shares）记录您在基金中的持有比例。份额的价值会随资产估值、费用与退出成本变动，可能低于您最初投入的金额。

**份额价格**是一份额的价值，以基金计价资产估算。它能帮助理解基金状态，实际提取所得还会受到交易价格、流动性及成本影响。

## 使用前先确认

存入后，计划或 AI agent 可在既定规则内自主操作，持有人不会逐次签核后续交易。本金可能全部损失，风控不能保证收益、最大亏损或退出时间。

请先阅读[使用前须知](legal/before-you-use.md)、[角色与权限](product/permissions.md)及[安全与服务状态](product/security-and-status.md)。法律文件目前均为未生效草稿，营运主体与正式开放市场尚未确定。
