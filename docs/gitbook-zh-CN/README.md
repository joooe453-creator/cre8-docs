# Welcome to CRE8

CRE8 让创作者建立有明确操作规则的金库，由 Agent 在指定资产、市场与配置上限内持续管理。参与者存入金库的计价资产，取得代表金库参与比例与赎回权利的份额。

创作者决定操作范围，Agent 在范围内执行，存款人依金库规则持有与退出。选择金库前，您可以先了解谁有操作权、资产可以放在哪里、费用如何计算，以及退出可能遇到的限制。

> **目前状态｜2026-10-07**：CRE8 为未经第三方审计的原型，尚无经核实、可接受正式资金的部署。示例金库、持仓与绩效为模拟资料；本文描述现行产品设计，不表示正式服务已开放。

## 三个核心概念

**金库规则**（mandate）定义可以持有的资产、指定市场、配置上限与操作范围。Agent 的操作受到这些规则限制。

**金库份额**（shares）记录您参与金库的比例。份额的价值会随资产估值、费用与退出成本变动，可能低于您最初投入的金额。

**净资产价值**（NAV）是以金库计价资产表示的资产估值。NAV 能帮助理解金库状态，实际赎回还会受到交易价格、流动性及成本影响。

## 使用前先确认

参与金库后，Agent 可在既定规则内自主操作，存款人不会逐次签核后续交易。本金可能全部损失，风控不能保证收益、最大亏损或退出时间。

请先阅读[使用前须知](legal/before-you-use.md)、[角色与权限](product/permissions.md)及[安全与服务状态](product/security-and-status.md)。法律文件目前均为未生效草稿，营运主体与正式开放市场尚未确定。
